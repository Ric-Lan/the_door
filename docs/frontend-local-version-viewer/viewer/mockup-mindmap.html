心智圖徽章與 L1 尺寸 — Before / After 對照

心智圖的整體 layout 與互動行為（中心節點 + 放射 L1 + 點 L1 觸發 info-panel） 維持現況不動。本頁只展示 § 10 改動的視覺項：徽章、L1 尺寸、toolbar 圖例。

不在改動範圍：右側 #info-panel 與心智圖的 SVG layout 演算法保持原樣。 生產檔請改 viewer/mindmap-popup.html 內：① 徽章 SVG block（rect/text） ② L1_W/L1_H 常數 ③ toolbar 上的 .tb-badge 列 ④ guide-panel 文案。
