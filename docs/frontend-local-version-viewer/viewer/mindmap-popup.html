如何閱讀心智圖

整體結構

P 中心節點：專案名稱，所有功能的根
L1 L1 功能節點：系統的主要功能分類，點擊可展開 L2
L2 L2 模組節點：功能內部的實作模組

L1 節點說明

▸ 箭頭方向代表展開狀態，▸ 點擊展開 L2 / ▾ 再點收合
⚠ N 該功能包含 N 個異常，需注意
Δ 有差異 新舊版本之間此功能有變更
節點下方小字顯示 L2 模組數量
點擊節點同時開啟右側詳情面板

L2 節點說明

⚠ 橙色框線 + ⚠ 標示：所屬功能含有異常，所有 L2 節點均會標示
節點寬度依標籤文字自動調整
HIGHMEDLOW 分析信心程度
3 圓角數字 = Source 節點數
