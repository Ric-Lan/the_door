# Frontend Local Version Viewer

本資料夾收納 The Door 本地版本驗核前端的規格與後續設計資料。

## 文件

| 文件 | 用途 |
|---|---|
| `spec.md` | 本地版本驗核前端的主要開發規格，包含 TDD、最小技術棧、資料契約、UI 邊界與驗收標準 |

## 放置規則

未來若新增相關資料，請放在本資料夾下：

- `requirements.md`：若需要拆分正式需求。
- `design.md`：若需要拆分實作設計。
- `tasks.md`：若需要拆分開發任務。
- `fixtures/`：只放測試用資料；mock 檔案必須在檔名標示 `mock`。

不要把前端 viewer 相關文件散放到 `docs/` 根目錄。
