# MD 純文字模擬格式規範 (MD Plain Text Simulation Format Specification)

本章定義 The Door 的 MD 純文字模擬圖格式——一套讓非技術人員無需說明即可閱讀的文字圖形格式，同時確保所有語意概念都有對應的 Mermaid 表示，為後續 Phase 的 Mermaid 渲染奠定基礎。

---

## 9.1 格式設計原則

MD 純文字模擬格式遵循以下設計原則：

| # | 原則 | 說明 |
|---|---|---|
| 1 | **非技術人員可讀** | 格式本身不需要額外說明，符號的語意從上下文即可理解 |
| 2 | **Mermaid 可轉換** | 每個 MD 文字慣例都有對應的 Mermaid 表示方式，確保 paper prototype 的語意概念能在後續 Phase 中用 Mermaid 實現 |
| 3 | **ASCII/Unicode 字元** | 使用 ASCII 和常見 Unicode 字元表示視覺狀態，不依賴特殊字型或渲染引擎 |
| 4 | **結構清晰** | 層級分明，使用分隔線、標題、群組框等結構元素組織內容 |
| 5 | **語意一致** | MD 格式中的符號語意與 Mermaid 圖形中的視覺編碼完全對應，不引入額外的語意歧義 |

## 9.2 節點表示法

節點使用**前綴符號 + 名稱**的格式，前綴符號編碼節點的觸發類型（L1）或變更狀態（Diff）：

**L1 觸發類型前綴：**

```
[U] 使用者登入                    ← 使用者觸發功能（圓角矩形）
[S] 每日報表產出                  ← 定時觸發功能（平行四邊形）
[E] 訂單完成後通知                ← 事件觸發功能（菱形）
```

**L1.5 結構區塊：**

```
認證模組 — 處理使用者身份驗證 [+]  ← 結構區塊（可展開至 L2）
  由使用者請求觸發                  ← 觸發機制副標題（斜體）

[基礎設施] 資料庫 | 快取 | 日誌    ← 基礎設施收攏區塊
```

**L2 模組層級：**

```
auth_service                       ← 模組（圓角矩形）
  ├─ token_validator               ← 子模組（較小圓角矩形）
  ├─ password_hasher               ← 子模組
  └─ /Redis Cache/                 ← 外部依賴（平行四邊形，斜線包裹）
```

## 9.3 邊（關係）表示法

邊使用**樹狀縮排 + 箭頭符號 + 標籤**的格式，箭頭樣式編碼關係類型：

```
[U] 使用者登入
  └──→ [U] 瀏覽商品目錄          "登入後可操作"      ← 實線箭頭（直接關係）
  └──→ [U] 管理個人資料          "登入後可操作"

[U] 建立訂單
  └──→ [E] 訂單確認通知          "完成後觸發"        ← 實線箭頭（完成後觸發）
  └- - → [S] 庫存同步            "可能相關"（推斷）   ← 虛線箭頭（推斷關係）
```

**箭頭符號對照：**

| 箭頭符號 | 關係類型 | 適用層級 | 說明 |
|---|---|---|---|
| `└──→` | 實線箭頭 | L1 / L1.5 / L2 | 直接關係（完成後觸發 / 呼叫 / 靜態呼叫） |
| `└- - →` | 虛線箭頭 | L1 / L1.5 / L2 | 間接關係（依賴結果 / 通知 / 推斷關係） |
| `└═══→` | 粗線箭頭 | L1.5 / L2 | 資料流（資料流向 / 資料依賴） |
| `└──✕` | 刪除線箭頭 | Diff 視圖 | 移除邊 |

## 9.4 視覺狀態標記

視覺狀態標記使用**方括號包裹的符號**，附加在節點行末，編碼 Diff 變更和範圍邊界狀態：

**Diff 變更標記：**

```
[+] 新功能名稱 .................. [新增]
[−] 已移除功能 .................. [移除]
[~] 屬性已變更的功能 ............ [屬性變更]
[≠] 依賴關係變更的功能 .......... [依賴變更]
    功能名稱（無變更）........... [未變更]
```

**範圍邊界標記：**

```
功能名稱 ....................... [scope: ✓]    ← 範圍內已完成
功能名稱 ....................... [scope: ⚠]    ← 超出範圍
功能名稱 ....................... [scope: ○]    ← 範圍內未完成
```

**Diff + 範圍組合標記：**

當 Diff 變更和範圍邊界同時呈現時，兩種標記並列顯示：

```
[+] 批次匯出功能 .............. [新增]     [scope: ⚠ 超出範圍]
[~] 使用者登入 ................ [屬性變更]  [scope: ✓ 範圍內]
[≠] 訂單處理 .................. [依賴變更]  [scope: ✓ 範圍內]
[−] 舊版報表 .................. [移除]     [scope: ✓ 範圍內]
    使用者註冊 ................ [未變更]
```

## 9.5 層級結構表示

MD 格式使用以下結構元素組織多層級內容：

**分隔線 + 層級標題：**

```
═══════════════════════════════════════════
  📍 L1 功能總覽
═══════════════════════════════════════════
```

- `═══` 雙線分隔線標示層級邊界
- `📍` emoji 標示當前層級名稱

**群組框：**

```
┌─ 使用者管理 ─────────────────────────┐
│  [U] 使用者註冊                       │
│  [U] 使用者登入                       │
│  [U] 修改個人資料                     │
└───────────────────────────────────────┘
```

- `┌─ ... ─┐` 頂框線包含群組標題
- `│ ... │` 側框線包裹群組內容
- `└─ ... ─┘` 底框線封閉群組

**關係區塊：**

```
關係：
  使用者登入 ──→ 建立訂單              "登入後可操作"
  建立訂單 ──→ 訂單確認通知            "完成後觸發"
```

## 9.6 Diff 視圖 MD 格式

Diff 視圖的 MD 格式包含三個部分：摘要行、變更列表、範圍標記。

**完整格式：**

```
═══════════════════════════════════════════
  📊 Diff 視圖：v1.2.0 → v1.3.0
═══════════════════════════════════════════

  [+] 批次匯出功能 .............. [新增]     [scope: ⚠ 超出範圍]
  [~] 使用者登入 ................ [屬性變更]  [scope: ✓ 範圍內]
  [≠] 訂單處理 .................. [依賴變更]  [scope: ✓ 範圍內]
  [−] 舊版報表 .................. [移除]     [scope: ✓ 範圍內]
      使用者註冊 ................ [未變更]
      修改個人資料 .............. [未變更]

摘要：新增 1 | 移除 1 | 修改 2（1 依賴變更、1 屬性變更）
範圍：✓ 範圍內 3 | ⚠ 超出範圍 1 | ○ 未完成 0
```

## 9.7 Mermaid 對照表

以下表格映射每個 MD 文字慣例到其對應的 Mermaid 表示方式，確保 paper prototype 的語意概念都能在後續 Phase 中用 Mermaid 實現：

| MD 文字慣例 | 語意 | Mermaid 對應 |
|---|---|---|
| `[U] 節點名稱` | 使用者觸發功能 | `f1["[U] 節點名稱"]`（圓角矩形） |
| `[S] 節點名稱` | 定時觸發功能 | `f1[/"[S] 節點名稱"/]`（平行四邊形） |
| `[E] 節點名稱` | 事件觸發功能 | `f1{"[E] 節點名稱"}`（菱形） |
| `模組 — 說明 [+]` | L1.5 可展開區塊 | `f1["模組 — 說明 [+]"]` |
| `[基礎設施] ...` | 基礎設施收攏區塊 | `subgraph Infrastructure["系統基礎設施"]` |
| `A ──→ B "標籤"` | 實線箭頭（直接關係） | `A -->\|"標籤"\| B` |
| `A - - → B "標籤"` | 虛線箭頭（間接/推斷） | `A -.->\|"標籤"\| B` |
| `A ═══→ B "標籤"` | 粗線箭頭（資料流） | `A ==>\|"標籤"\| B` |
| `[+] 節點 [新增]` | Diff 新增 | `class f1 diff_added`（綠色填充） |
| `[−] 節點 [移除]` | Diff 移除 | `class f1 diff_removed`（紅色填充） |
| `[~] 節點 [屬性變更]` | Diff 屬性變更 | `class f1 diff_attr_changed`（淺橘填充） |
| `[≠] 節點 [依賴變更]` | Diff 依賴關係變更 | `class f1 diff_dep_changed`（深橘填充） |
| `節點 [未變更]` | 未變更（降調） | `class f1 unchanged`（極淺灰填充） |
| `[scope: ✓]` | 範圍內已完成 | `f1["節點名稱 ✓<sup>scope</sup>"]` |
| `[scope: ⚠]` | 超出範圍 | `f1["節點名稱 ⚠<sup>scope</sup>"]` |
| `[scope: ○]` | 範圍內未完成 | `f1["節點名稱 ○<sup>scope</sup>"]` |
| `⚑ 已知漏洞` | L2 異常：漏洞 | `class f1 vuln_high` 或 `vuln_medium` |
| `⚠ 邏輯死路` | L2 異常：邏輯死路 | `class f1 logic_dead` |
| `◎ 死碼` | L2 異常：死碼 | `class f1 dead_code` |
| `⊙ 不確定邊界` | L2 異常：不確定邊界 | `class f1 uncertain` |
| `┌─ 群組名 ─┐ ... └─┘` | 視覺群組 | `subgraph 群組名["群組名"]` |
| `═══ 📍 層級名 ═══` | 層級分隔 | Tab 切換 UI / 獨立 Mermaid 圖 |
| `📍 目前視圖：...` | 當前層級指示器 | UI 導航列 |
| `📊 Diff 視圖：...` | Diff 摘要標頭 | Diff 面板標頭 |

## 9.8 完整 MD 範例：L1 + L1.5 + Diff 視圖

以下是一個完整的 MD 純文字模擬範例，涵蓋 L1 功能總覽、L1.5 結構概覽、以及 Diff 視圖，使用虛構的「線上商店」系統。此範例驗證 MD 格式能完整表達所有視覺語言概念。

```
═══════════════════════════════════════════════════════════════
  📍 L1 功能總覽
═══════════════════════════════════════════════════════════════

┌─ 使用者管理 ─────────────────────────────────────────────┐
│  [U] 使用者註冊                                           │
│  [U] 使用者登入                                           │
│  [U] 修改個人資料                                         │
└───────────────────────────────────────────────────────────┘

┌─ 商品與訂單 ─────────────────────────────────────────────┐
│  [U] 瀏覽商品目錄                                         │
│  [U] 建立訂單                                             │
│  [U] 退貨處理                                             │
│  [E] 訂單確認通知                                         │
│  [S] 每日庫存同步                                         │
└───────────────────────────────────────────────────────────┘

關係：
  使用者登入 ──→ 瀏覽商品目錄            "登入後可操作"
  使用者登入 ──→ 建立訂單                "登入後可操作"
  建立訂單 ──→ 訂單確認通知              "完成後觸發"
  建立訂單 - - → 每日庫存同步            "可能相關"（推斷）
  建立訂單 ──→ 退貨處理                  "完成後可退貨"


═══════════════════════════════════════════════════════════════
  📍 L1.5 結構概覽
═══════════════════════════════════════════════════════════════

  認證模組 — 處理使用者身份驗證 [+]
    由使用者請求觸發

  商品模組 — 管理商品資訊與庫存 [+]
    由使用者請求觸發

  訂單模組 — 管理訂單生命週期 [+]
    由使用者請求觸發

  通知服務 — 發送各類通知給使用者 [+]
    由其他功能完成後通知

  排程服務 — 執行定時任務 [+]
    定時自動執行

  [基礎設施] 資料庫 | 快取 | 日誌 （點擊展開）

關係：
  認證模組 ──→ 商品模組                  "呼叫"
  認證模組 ──→ 訂單模組                  "呼叫"
  訂單模組 - - → 通知服務                "通知"
  訂單模組 ═══→ [基礎設施]               "資料流向"
  商品模組 ═══→ [基礎設施]               "資料流向"
  排程服務 ──→ 商品模組                  "呼叫"


═══════════════════════════════════════════════════════════════
  📊 Diff 視圖：v1.2.0 → v1.3.0
═══════════════════════════════════════════════════════════════

┌─ 使用者管理 ─────────────────────────────────────────────┐
│  [~] 使用者登入 .............. [屬性變更]  [scope: ✓ 範圍內] │
│      使用者註冊 .............. [未變更]                      │
│      修改個人資料 ............ [未變更]                      │
└───────────────────────────────────────────────────────────┘

┌─ 商品與訂單 ─────────────────────────────────────────────┐
│  [≠] 訂單處理 ................ [依賴變更]  [scope: ✓ 範圍內] │
│  [−] 舊版報表 ................ [移除]     [scope: ✓ 範圍內] │
│  [+] 批次匯出功能 ............ [新增]     [scope: ⚠ 超出範圍]│
│      瀏覽商品目錄 ............ [未變更]                      │
│      退貨處理 ................ [未變更]                      │
│      訂單確認通知 ............ [未變更]                      │
│      每日庫存同步 ............ [未變更]                      │
└───────────────────────────────────────────────────────────┘

邊變更：
  批次匯出功能 ──→ 訂單處理              [新增邊] "匯出訂單資料"
  舊版報表 ──✕ 訂單處理                  [移除邊]

摘要：新增 1 | 移除 1 | 修改 2（1 依賴變更、1 屬性變更）
範圍：✓ 範圍內 3 | ⚠ 超出範圍 1 | ○ 未完成 0
```
