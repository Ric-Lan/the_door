# 層級切換視覺規範 (Layer Switching Visual Specification)

層級切換是 The Door 圖形語言的核心互動機制——使用者透過切換層級來改變觀看系統的視角。本章定義 L1 ↔ L1.5 的平行 Tab 切換、L2 的點擊展開、展開指示器、當前層級指示器、以及完整的導航場景。

---

## 7.1 L1 ↔ L1.5：平行 Tab 切換

L1（功能總覽）和 L1.5（結構概覽）是**同等地位的平行視角**，不是父子階層。使用者透過 Tab 列在兩者之間切換，就像在同一份文件的不同「觀點」之間切換。

**Wireframe — Tab 列與活動 Tab 高亮：**

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  ┌───────────────────┐  ┌───────────────────┐           │
│  │ ▶ L1 功能總覽     │  │   L1.5 結構概覽   │           │
│  │   （功能視角）     │  │   （結構視角）     │           │
│  └───────────────────┘  └───────────────────┘           │
│  ━━━━━━━━━━━━━━━━━━━━━                                  │  ← 活動 Tab 底線高亮
│                                                         │
│  📍 目前視圖：L1 功能總覽                                │
│                                                         │
│  ┌─ 使用者管理 ─────────────────────────────────┐       │
│  │  [U] 使用者註冊                               │       │
│  │  [U] 使用者登入                               │       │
│  │  [U] 修改個人資料                             │       │
│  └───────────────────────────────────────────────┘       │
│                                                         │
│  ┌─ 訂單處理 ───────────────────────────────────┐       │
│  │  [U] 建立訂單                                 │       │
│  │  [E] 訂單確認通知                             │       │
│  └───────────────────────────────────────────────┘       │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**切換到 L1.5 後：**

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  ┌───────────────────┐  ┌───────────────────┐           │
│  │   L1 功能總覽     │  │ ▶ L1.5 結構概覽   │           │
│  │   （功能視角）     │  │   （結構視角）     │           │
│  └───────────────────┘  └───────────────────┘           │
│                          ━━━━━━━━━━━━━━━━━━━━           │  ← 活動 Tab 底線高亮
│                                                         │
│  📍 目前視圖：L1.5 結構概覽                              │
│                                                         │
│  認證模組 — 處理使用者身份驗證 [+]                        │
│    由使用者請求觸發                                      │
│                                                         │
│  訂單模組 — 管理訂單生命週期 [+]                          │
│    由使用者請求觸發                                      │
│                                                         │
│  通知服務 — 發送各類通知 [+]                              │
│    由其他功能完成後通知                                   │
│                                                         │
│  [基礎設施] 資料庫 | 快取 | 日誌 （點擊展開）             │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**Tab 切換視覺語意：**

| 設計元素 | 說明 |
|---|---|
| Tab 並列排列 | 兩個 Tab 水平並列，視覺上等高等寬，傳達「同等地位」 |
| 活動 Tab 高亮 | 當前選中的 Tab 使用底線高亮（`━━━`）和 ▶ 前綴標記 |
| 非活動 Tab 降調 | 未選中的 Tab 文字顏色降調，但仍可點擊 |
| 副標題 | 每個 Tab 下方附帶副標題（「功能視角」/「結構視角」），幫助使用者理解兩個視角的差異 |
| 無父子暗示 | Tab 之間沒有箭頭、縮排或任何暗示階層的視覺元素 |

**設計理由：** L1 和 L1.5 回答不同的問題（「系統能做什麼」vs「系統由哪些部分組成」），但它們的抽象層級相近，都面向非技術使用者。Tab 切換傳達「這是同一個系統的兩種觀看方式」，而非「L1.5 是 L1 的子層級」。

## 7.2 L2：點擊展開

L2 不是獨立的全畫面視圖，而是從 L1.5 的結構區塊**點擊展開**進入的詳細視圖。這種互動方式傳達「向下鑽取」的語意——使用者選擇一個區塊，展開查看其內部模組互動細節。

**Wireframe — 展開前（收合狀態）：**

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  L1 功能總覽  │  ▶ L1.5 結構概覽                         │
│                 ━━━━━━━━━━━━━━━━━━                       │
│                                                         │
│  📍 目前視圖：L1.5 結構概覽                              │
│                                                         │
│  ┌─────────────────────────────────────────────┐        │
│  │  認證模組 — 處理使用者身份驗證          [+]  │        │
│  │  由使用者請求觸發                            │        │
│  └─────────────────────────────────────────────┘        │
│                                                         │
│  ┌─────────────────────────────────────────────┐        │
│  │  訂單模組 — 管理訂單生命週期            [+]  │        │
│  │  由使用者請求觸發                            │        │
│  └─────────────────────────────────────────────┘        │
│                                                         │
│  ┌─────────────────────────────────────────────┐        │
│  │  通知服務 — 發送各類通知                [+]  │        │
│  │  由其他功能完成後通知                        │        │
│  └─────────────────────────────────────────────┘        │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**Wireframe — 展開後（認證模組展開至 L2）：**

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  L1 功能總覽  │  ▶ L1.5 結構概覽                         │
│                 ━━━━━━━━━━━━━━━━━━                       │
│                                                         │
│  📍 目前視圖：L1.5 結構概覽 > 認證模組 (L2)              │
│                                                         │
│  ┌─────────────────────────────────────────────┐        │
│  │  認證模組 — 處理使用者身份驗證          [−]  │        │
│  │  由使用者請求觸發                            │        │
│  │                                              │        │
│  │  ┌─ L2 詳細視圖 ──────────────────────┐     │        │
│  │  │                                     │     │        │
│  │  │  auth_service                       │     │        │
│  │  │    ├──→ token_validator             │     │        │
│  │  │    │     ⚑ 已知漏洞（中危）         │     │        │
│  │  │    ├──→ password_hasher             │     │        │
│  │  │    │     ◎ 死碼                     │     │        │
│  │  │    └- - → Redis Cache  [推斷]       │     │        │
│  │  │                                     │     │        │
│  │  └─────────────────────────────────────┘     │        │
│  └─────────────────────────────────────────────┘        │
│                                                         │
│  ┌─────────────────────────────────────────────┐        │
│  │  訂單模組 — 管理訂單生命週期            [+]  │        │
│  │  由使用者請求觸發                            │        │
│  └─────────────────────────────────────────────┘        │
│                                                         │
│  ┌─────────────────────────────────────────────┐        │
│  │  通知服務 — 發送各類通知                [+]  │        │
│  │  由其他功能完成後通知                        │        │
│  └─────────────────────────────────────────────┘        │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**展開/收合視覺規則：**

| 狀態 | 指示器 | 視覺效果 |
|---|---|---|
| 收合（預設） | `[+]` | 節點右側顯示 `[+]`，暗示「可展開」 |
| 展開 | `[−]` | 節點右側顯示 `[−]`，暗示「可收合」；節點下方展開 L2 詳細視圖區域 |

**展開行為規則：**

- 同一時間可以展開多個 L1.5 區塊的 L2 視圖
- 展開不影響其他未展開的區塊
- 展開區域在視覺上內嵌於 L1.5 區塊內部，使用縮排和邊框區分
- 點擊 `[−]` 收合後，L2 詳細視圖隱藏，恢復為 `[+]` 狀態

## 7.3 L1.5 節點 [+] 展開指示器規格

`[+]` 展開指示器是 L1.5 節點上的視覺提示，告知使用者「此區塊可以展開查看 L2 詳細視圖」。

**指示器規格：**

| 屬性 | 規格 |
|---|---|
| 符號 | `[+]`（收合狀態）/ `[−]`（展開狀態） |
| 位置 | 節點標籤右側末尾 |
| 互動 | 可點擊，點擊切換展開/收合狀態 |
| 預設狀態 | 收合（`[+]`） |
| 適用範圍 | 所有 L1.5 結構區塊（基礎設施區塊除外） |

**Mermaid 實現：**

```
auth["認證模組 — 處理使用者身份驗證 [+]<br/><i>由使用者請求觸發</i>"]
```

展開後：

```
auth["認證模組 — 處理使用者身份驗證 [−]<br/><i>由使用者請求觸發</i>"]
```

**基礎設施區塊的展開：** 基礎設施區塊使用「（點擊展開）」文字提示而非 `[+]` 指示器，因為基礎設施展開的是其組成元件（資料庫、快取、日誌），不是 L2 詳細視圖。

## 7.4 當前層級指示器

畫面上始終顯示當前視圖層級，讓使用者隨時知道自己「在哪裡」。

**指示器格式：**

```
📍 目前視圖：[層級名稱]
```

**各層級的指示器顯示：**

| 使用者位置 | 指示器顯示 |
|---|---|
| L1 功能總覽 | `📍 目前視圖：L1 功能總覽` |
| L1.5 結構概覽 | `📍 目前視圖：L1.5 結構概覽` |
| L1.5 + 某區塊展開至 L2 | `📍 目前視圖：L1.5 結構概覽 > 認證模組 (L2)` |
| L1.5 + 多區塊展開至 L2 | `📍 目前視圖：L1.5 結構概覽 > 認證模組 (L2), 訂單模組 (L2)` |
| Diff 視圖（L1） | `📍 目前視圖：L1 功能總覽 — Diff v1.2.0 → v1.3.0` |
| Diff 視圖（L1.5） | `📍 目前視圖：L1.5 結構概覽 — Diff v1.2.0 → v1.3.0` |

**指示器規則：**

- 指示器固定在畫面頂部（Tab 列下方），不隨捲動消失
- 使用 📍 emoji 作為視覺錨點，讓使用者快速定位
- 展開 L2 時，使用 `>` 符號表示鑽取路徑
- 多個 L2 展開時，以逗號分隔列出所有展開的區塊名稱
- Diff 視圖時，附加版本比較資訊

以下是一個完整的導航場景，展示使用者從 L1 開始，經過 Tab 切換、L2 展開、發現異常、收合回 L1.5 的完整流程：

**導航場景摘要：**

| 步驟 | 動作 | 視圖變化 | 層級指示器 |
|---|---|---|---|
| 1 | 開啟系統 | L1 功能總覽 | `📍 L1 功能總覽` |
| 2 | 點擊 L1.5 Tab | 切換到 L1.5 結構概覽 | `📍 L1.5 結構概覽` |
| 3 | 點擊認證模組 `[+]` | 展開 L2 詳細視圖 | `📍 L1.5 結構概覽 > 認證模組 (L2)` |
| 4 | 點擊 ⚑ 異常標示 | 進入疑義路徑 | （疑義詳情面板） |
| 5 | 點擊認證模組 `[−]` | 收合 L2，回到 L1.5 | `📍 L1.5 結構概覽` |

此場景驗證了完整的導航流程：L1 → Tab 切換 L1.5 → 點擊展開 L2 → 發現異常 → 收合回 L1.5。使用者在每個步驟都有明確的視覺提示（Tab 高亮、`[+]`/`[−]` 指示器、📍 層級指示器），不會迷失在層級切換中。
